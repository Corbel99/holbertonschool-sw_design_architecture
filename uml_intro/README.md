# UML Introduction

This directory contains my work for the Holberton School **Introduction to UML Modeling** project.

## Topics

The project focuses on the following UML concepts:

* UML Class Diagrams
* UML Sequence Diagrams
* Association
* Generalization
* Aggregation
* Composition
* Realization
* Dependency

## Project

The main exercise consists of modeling a **Library Loan System** using UML.

The diagrams are written using **Mermaid** and must respect the structure, naming conventions, relationships, and multiplicities specified by the project requirements.
