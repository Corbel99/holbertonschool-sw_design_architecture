# Holberton School — Software Design & Architecture

This repository contains my work for the Holberton School **Software Design & Architecture** projects.

The projects cover software design concepts such as:

* Object-Oriented Programming (OOP)
* UML modeling
* Class diagrams
* Sequence diagrams
* Software architecture
* Design patterns

Each project is organized into its own directory and follows the requirements and constraints provided by Holberton School.
